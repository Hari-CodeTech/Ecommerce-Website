# LUMINA LUXE - Modern E-Commerce Web Application

A modern, high-end e-commerce web application built using **HTML5**, **CSS3**, and **Bootstrap 5.3**. Designed with glassmorphism, dynamic animations, dark/light mode toggle, and rich interactivity.

---

## ✨ Features

- **Design System & Aesthetics**:
  - Dark Mode & Light Mode switch with persistent state.
  - Glassmorphic panels with subtle neon glowing accents.
  - Responsive layouts optimized for desktop, tablet, and mobile displays.
  - Google Fonts typography (**Outfit** & **Plus Jakarta Sans**).
- **Product Catalog & Discovery**:
  - 12 comprehensive curated items across Audio & Tech, Haute Horlogerie, Designer Apparel, Carbon Footwear, and Minimalist Living.
  - Interactive department / category filter pills.
  - Live search bar filtering by keyword and description.
  - Real-time price slider filtering ($50 – $600).
  - Multi-criteria sorting (Featured, Price Low to High, Price High to Low, Top Customer Rated, Alphabetical).
- **Interactive Modals & Drawers**:
  - **Slide-out Offcanvas Cart**:
    - Item quantity steppers (`+` / `-`) and instant item removal.
    - Real-time **Free Shipping Progress Tracker** (target: $150).
    - Promo voucher validation (test with `NOVA25` for 25% off or `SAVE10` for 10% off).
    - Dynamic calculation of subtotal, voucher discounts, 8% sales tax, and shipping.
  - **Quick View Modal**:
    - Multi-angle product photo gallery with thumbnail switcher.
    - Finish swatch picker and size selection badges.
    - Real-time stock status indicator.
  - **Offcanvas Wishlist**:
    - Save items with one click and move them directly to the cart.
  - **Express Checkout Modal**:
    - Complete simulated checkout flow with shipping address and payment methods (Credit Card, Apple Pay, PayPal).
    - Simulated transaction processing with order confirmation view, tracking reference ID, and estimated arrival date.
- **Engagement & Urgency**:
  - Flash deals banner with a live ticking countdown timer (Hours, Mins, Secs) and inventory claim progress bars.
  - Verified customer reviews with star ratings and testimonials.
  - VIP Club newsletter invitation banner with immediate feedback toasts.
  - Toast notification system for all cart and wishlist actions.

## 🚀 Getting Started

### 1. Direct Browser Opening
Simply double-click or open [`index.html`](file:///d:/e-com/index.html) in any modern web browser (Chrome, Edge, Firefox, Safari).

### 2. Using Local Web Server
You can also run a local server:
```bash
# Using Python
python -m http.server 8080
```
Then navigate to: **`http://localhost:8080`**
